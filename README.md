Student Record Management System
This is my internship project. I made a CLI app in Python to manage student records. It can add, view, search, edit and delete students. All data is saved in a CSV file.

How to run
python student_manager.py
What it does
Add new student (name, age, marks, subject)
View all students in a table
Search student by name or ID
Edit student details
Delete a student
Show basic stats like average marks
Files
student_manager.py - main file with all the code
test_student_manager.py - unit tests
sample_data.csv - some sample data to test with
How to run tests
python test_student_manager.py
What I learned
how to read and write CSV files in python
using dictionaries and lists to store data
try except for handling wrong inputs
writing basic unit tests
how CRUD operations work
breaking code into functions
Requirements
Python 3 (no extra libraries needed)
