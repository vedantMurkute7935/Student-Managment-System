# Student Record Management System

A simple Python CLI (Command Line Interface) project to manage student records using file handling and CSV files.

---

# 📌 Project Description

The Student Record Management System allows users to:

- Add student records
- View all students
- Search student details
- Edit student information
- Delete student records

The project stores data in a CSV file so records remain saved permanently.

---

# 🚀 Features

✅ Add Student  
✅ View Students
